数据迁移：浏览器 localStorage → Supabase

在原来那台浏览器里打开本页（用 node server.js 或 vercel dev 启动）， 确认云端已连通后点击「一键导入云端」，即可把本机现有数据一次性写入 Supabase。

1. 连接状态

正在检测…

  • 未配置 Supabase 环境变量时，工作台会继续使用 localStorage，功能不受影响。
  • 本地请在项目根目录 .env.local 增加 SUPABASE_URL 与 SUPABASE_ANON_KEY；Vercel 部署请在项目环境变量中配置。
  • 表结构请先执行 supabase/schema.sql。
